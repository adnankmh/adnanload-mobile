# ADNANLOAD 2.3.1 — منع اختلاط ملفات التنزيل

- مجلد مستقل لكل عملية تنزيل وسائط، حتى عند تكرار اسم الفيديو أو تشغيل عمليتين معًا. المحاولات التلقائية لنفس العملية تحتفظ بمجلدها.
- أسماء المستخدم نصوص حرفية؛ لا تُفسّر رموز `%` بوصفها قالبًا لمحرك التنزيل.
- التحقق من وجود ملف صوت أو فيديو غير فارغ؛ الصور وملفات JSON وملفات التنزيل الجزئي لا تكفي لإعلان النجاح.
- لا يُقبل مسار ملف مكتمل من خارج مجلد العملية، ولا يُختار ملف عشوائي عند وجود أكثر من مرشح.
- استخدام اسم الملف النهائي وامتداده الصحيحين في العرض والتصدير بعد التحويل.
- إضافة بناء وفحوص GitHub Actions لطلبات التعديل قبل دمجها.

هذه إصلاحات لتنظيم المخرجات والتحقق منها. لا تثبت نجاح التنزيل من كل مزوّد، ولا تتجاوز تسجيل الدخول أو DRM. يلزم اختبار فيديو عام وقائمة تشغيل على هاتف Android.
